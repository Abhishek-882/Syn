# Post-Deploy Web Exploration & Interactive Sweeper
Local dump of post-deploy-web-exploring methodology.
Target: Autonomous testing and screenshot capture for UX audit.
Methodology:
1. Initialize headless browser context with high resolution (1440x900 or 1920x1080).
2. Monitor console errors and page errors.
3. Systematically test interactive elements.
4. Capture high-resolution screenshot at every step.
5. Log timing, status, bounding box, and DOM verification details.
6. Record failures and evaluate against power-user criteria.
